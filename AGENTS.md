# Project Instructions

Before making UI, layout, spacing, typography, component styling, or visual changes, read `DESIGN_SYSTEM.md` and follow it strictly.

Do not modify `apps/web/src/components/ui/*` for screen-specific design needs unless explicitly requested. Prefer composition, `className`, and app-level CSS in `apps/web/src/styles.css`.

Keep `shadcn/ui` components aligned with the configured base style unless explicitly asked to customize them.
